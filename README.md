# AP2 FISI Tagestraining

Offline-Lern-App für die Abschlussprüfung Teil 2 Fachinformatiker Systemintegration: tägliche Quizrunde mit Lernkartei-Wiederholung und generierten Rechenaufgaben, dazu der Lernpfad mit 22 Schritten.

Aufs Handy: Seite öffnen → „Zum Home-Bildschirm“. Danach läuft alles ohne Internet, der Fortschritt bleibt auf dem Gerät gespeichert.
